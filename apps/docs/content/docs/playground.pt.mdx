Tudo abaixo usa Geração local no navegador: sem Gateway, API route, server
action, chave de API ou endpoint de inferência. Escolha o Gemini Nano gerenciado
no Chrome quando disponível ou ative explicitamente o fallback Gemma. Não há
downloads automáticos nem troca silenciosa de runtime.

<Playground />

## Experimente

- Envie `Escreva uma resposta de suporte para Ana sobre um pedido atrasado (ana@acme.com).` em qualquer chat.
- O inspector mostra o histórico protegido e o conteúdo atual exatos entregues
  ao runtime, nunca o mapping privado nem o input original.
- A resposta é restaurada localmente e a UI mostra o email original.
- Quando o Gemma está em cache, **Clear cached model** remove o cache do
  navegador; isso não afeta o Gemini Nano gerenciado separadamente pelo Chrome.
- **New chat** espera stop e limpeza do runtime; só então limpa histórico,
  sessão, erro e inspection da aba e cria uma nova sessão.

Cada aba montada mantém conversa privada, sessão, histórico, observer e mapping
independentes. Um gate permite uma geração por vez: o chat proprietário pode
parar; submit e reset do outro ficam desabilitados até a limpeza liberar o gate.
Ambos usam seus adaptadores públicos reais de Vercel AI SDK e TanStack. O
runtime interno da documentação não é uma API pública de `local-pii`.

## Divulgação do runtime

- Gemini Nano é gerenciado pelo navegador e exige Chrome desktop, hardware e
  Prompt API compatíveis. Seus recursos não são download de artefatos controlado
  por esta página.
- Gemma é `onnx-community/gemma-3-270m-it-ONNX`, revisão
  `2dbbfdb1b59bd034eb959428c6a7da9dd7ea27f0` e q4f16 WebGPU. Seus seis arquivos
  pinados do modelo totalizam 293.284.073 bytes. A primeira ativação também pode
  baixar 23.614.439 bytes não comprimidos de arquivos versionados de suporte do
  ONNX Runtime Web, totalizando aproximadamente 316.898.512 bytes de artefatos
  estáticos (~317 MB antes da compressão de transferência). As origens são
  `https://huggingface.co`, `https://*.cdn.hf.co` e `https://cdn.jsdelivr.net`;
  leia o [model card e os termos da licença Gemma](https://huggingface.co/onnx-community/gemma-3-270m-it-ONNX)
  antes de ativar.
- Downloads explícitos contêm apenas recursos estáticos do modelo e do runtime,
  sem conteúdo do usuário. Prompts, valores restaurados, mappings e inspector
  não vão para endpoint da aplicação.
- Modelos de Geração pequenos são úteis nesta demonstração, mas qualidade e
  raciocínio variam. Traduzir a interface não garante qualidade igual em inglês,
  português e alemão.

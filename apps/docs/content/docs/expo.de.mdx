Das Q4-[Rampart](https://huggingface.co/nationaldesignstudio/rampart)-Modell
ist ein **Erkennungsmodell** für Namen, Adressen und IDs. Es läuft lokal über
`onnxruntime-react-native`; das separate Generierungsmodell erhält nur
geschützten Inhalt.

```bash
bun add onnxruntime-react-native expo-asset expo-file-system @local-pii/model-rampart
bun run fetch-model
```

Erforderlich ist ein Dev Client / Prebuild, nicht Expo Go.

## Metro

```js
const { getDefaultConfig } = require("expo/metro-config")
const { withLocalPiiMetro } = require("local-pii/metro")

module.exports = withLocalPiiMetro(getDefaultConfig(__dirname))
```

## Erkennung konfigurieren

```ts
import { createAnonymizer } from "local-pii"
import { rampart } from "local-pii/expo"

const privacy = createAnonymizer({
  detection: rampart({
    model: require("@local-pii/model-rampart/assets/rampart-q4.onnx"),
  }),
})
```

Wenn das Modell nicht lädt, fällt der Standard auf deterministische Erkennung
zurück; `strict: true` wirft stattdessen. `ner:` bleibt ein Kompatibilitätsalias.
`CITY`, `STATE` und `ZIP_CODE` bleiben standardmäßig im Text; `keep` oder
`redact` ändern diese Richtlinie.

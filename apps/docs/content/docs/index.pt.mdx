O **local-pii** protege informação pessoal antes que ela saia do dispositivo.
Um adaptador de Detecção alimenta o anonymizer, uma sessão de privacidade
possui uma conversa privada, e um adaptador de Geração ou callback inline chama
o modelo de Geração escolhido. Apenas conteúdo protegido sai; o mapping privado
fica local.

```ts
import { createAnonymizer, token } from "local-pii"
import { rampartWeb } from "local-pii/web"
import { runInlineText } from "local-pii/inline"

const privacy = createAnonymizer({
  detection: rampartWeb(),
  placeholders: token(),
})
const conversation = privacy.createSession()
const answer = await runInlineText({
  session: conversation,
  input: "Email ana@acme.com",
  call: (protectedContent, { signal }) =>
    generationModel.generate(protectedContent, { signal }),
})
```

Rampart Q4 é um modelo de Detecção. Gemini Nano, Gemma e modelos de provedor
são modelos de Geração. `ner:` continua como alias de compatibilidade para
`detection:`.

## Instalação

```bash
bun add local-pii
```

A Detecção determinística (emails, telefones, cartões, IBAN, SSN, IP e URLs)
funciona no React Native, navegador e Node sem dependências extras.

## Escolha um adaptador de Detecção

- **Expo / React Native** → [`rampart()`](/pt/docs/expo) via
  `onnxruntime-react-native`.
- **Navegador / web** → [`rampartWeb()`](/pt/docs/browser) via
  `onnxruntime-web` (WASM/WebGPU).

`ner:` é suportado durante a migração, mas aplicações novas devem usar
`detection:`.

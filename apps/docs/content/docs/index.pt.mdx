O **local-pii** protege informação pessoal antes que ela cruze a fronteira do
provedor de Geração escolhido.
Um adaptador de Detecção alimenta o anonymizer, uma sessão de privacidade
possui uma conversa privada, e um adaptador de Geração ou callback inline chama
o modelo de Geração escolhido. Conteúdo semântico protegido cruza a fronteira
do provedor; reasoning, metadados e opções opacos permanecem responsabilidade
do chamador. O mapping privado fica dentro da fronteira de confiança dele.

```ts
import { createAnonymizer, token } from "@local-pii/core"
import { rampartWeb } from "@local-pii/core/web"
import { runInlineText } from "@local-pii/core/inline"

const privacy = createAnonymizer({
  detection: rampartWeb(),
  placeholders: token(),
})
const conversation = privacy.createSession()
const answer = await runInlineText({
  session: conversation,
  input: "Email ana@acme.com",
  call: (protectedContent, { signal }) =>
    generationModel.generate(protectedContent, { signal }),
})
```

Rampart Q4 é um modelo de Detecção. Gemini Nano, Gemma e modelos de provedor
são modelos de Geração. `ner:` continua como alias de compatibilidade para
`detection:`.

## Instalação

```bash
bun add @local-pii/core onnxruntime-web @local-pii/model-rampart
```

O quickstart usa Rampart no navegador, cujos peers opcionais são
`onnxruntime-web` e `@local-pii/model-rampart`. A Detecção determinística
(emails, telefones, cartões, IBAN, SSN, IP e URLs) funciona apenas com
`@local-pii/core` no React Native, navegador e Node.

## Escolha um adaptador de Detecção

- **Expo / React Native** → [`rampart()`](/pt/docs/expo) via
  `onnxruntime-react-native`.
- **Navegador / web** → [`rampartWeb()`](/pt/docs/browser) via
  `onnxruntime-web` (WASM/WebGPU).

`ner:` é suportado durante a migração, mas aplicações novas devem usar
`detection:`.

---
title: Browser-Erkennung
description: Den Rampart-Erkennungsadapter im Browser mit onnxruntime-web (WASM + WebGPU) ausführen.
---

Der reine TypeScript-Kern läuft im Browser. `@local-pii/core/web` liefert den
Rampart-Q4-**Erkennungsadapter** für Namen, Adressen und IDs, bevor ein
Generierungsmodell geschützten Inhalt erhält.

```bash
bun add @local-pii/core onnxruntime-web @local-pii/model-rampart
```

## Erkennung ohne Konfiguration

```ts
import { createAnonymizer } from "@local-pii/core"
import { rampartWeb } from "@local-pii/core/web"

const privacy = createAnonymizer({ detection: rampartWeb() })
const { redactedText } = await privacy.anonymize("Hi, I'm João Silva")
```

Standardmäßig werden Modell, Vokabular und Labels (14,7 MB) von der
Rampart-Quelle geladen. Das Laden erfolgt faul: Die erste Anonymisierung startet
das Laden der Rampart-Artefakte und -Runtime. Dieser Artefakt-Download enthält
keinen Benutzerinhalt. Für Produktion sind selbst gehostete, gepinnte Assets
und eine Content Security Policy vorzuziehen.

## Selbst hosten

```ts
import { createAnonymizer } from "@local-pii/core"
import { rampartAssets, rampartWeb } from "@local-pii/core/web"

const privacy = createAnonymizer({
  detection: rampartWeb({
    model: "/models/rampart-q4.onnx",
    vocab: rampartAssets.vocab,
    labels: rampartAssets.labels,
    wasmPaths: "/ort/",
    executionProviders: ["webgpu", "wasm"],
  }),
})
```

Der Adapter fällt von WebGPU auf WASM zurück. Danach wird ein separater
Generierungsadapter oder `runInlineText` gewählt. `ner:` bleibt als
Kompatibilitätsschreibweise für `detection:` akzeptiert.

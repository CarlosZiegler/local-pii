O modelo Q4 [Rampart](https://huggingface.co/nationaldesignstudio/rampart) é um
**modelo de Detecção** para nomes, endereços e IDs. Ele roda localmente via
`onnxruntime-react-native`; o modelo separado de Geração recebe somente
conteúdo protegido.

```bash
bun add onnxruntime-react-native expo-asset expo-file-system @local-pii/model-rampart
```

É necessário dev client / prebuild, não Expo Go.

## Metro

```js
const { getDefaultConfig } = require("expo/metro-config")
const { withLocalPiiMetro } = require("@local-pii/core/metro")

module.exports = withLocalPiiMetro(getDefaultConfig(__dirname))
```

## Configurar a Detecção

```ts
import { createAnonymizer } from "@local-pii/core"
import { rampart } from "@local-pii/core/expo"

const privacy = createAnonymizer({
  detection: rampart({
    model: require("@local-pii/model-rampart/assets/rampart-q4.onnx"),
  }),
})
```

O carregamento é preguiçoso: a primeira anonimização resolve o asset empacotado
e inicia o runtime do Rampart. Aplicações que consomem o pacote publicado do
modelo não executam o script de desenvolvimento `fetch-model` do monorepo.

Se o modelo não carregar ou a inferência falhar, a Detecção configurada falha
de forma fechada por padrão. Use `strict: false` apenas quando o fallback para
Detecção determinística for uma política intencional do produto. `ner:`
permanece alias de compatibilidade. `CITY`, `STATE` e `ZIP_CODE` ficam no texto
por padrão; use `keep` ou `redact` para alterar essa política.

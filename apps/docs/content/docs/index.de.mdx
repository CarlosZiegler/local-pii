**local-pii** schützt persönliche Informationen, bevor sie das Gerät verlassen.
Ein Erkennungs-Adapter speist den Anonymizer, eine Privacy-Session gehört zu
einer privaten Konversation, und ein Generierungs-Adapter oder Inline-Callback
ruft das gewählte Generierungsmodell auf. Nur geschützter Inhalt verlässt das
Gerät; das private Mapping bleibt lokal.

```ts
import { createAnonymizer, token } from "local-pii"
import { rampartWeb } from "local-pii/web"
import { runInlineText } from "local-pii/inline"

const privacy = createAnonymizer({
  detection: rampartWeb(),
  placeholders: token(),
})
const conversation = privacy.createSession()
const answer = await runInlineText({
  session: conversation,
  input: "E-Mail ana@acme.com",
  call: (protectedContent, { signal }) =>
    generationModel.generate(protectedContent, { signal }),
})
```

Rampart Q4 ist ein Erkennungsmodell. Gemini Nano, Gemma und Provider-Modelle
sind Generierungsmodelle. `ner:` bleibt der Kompatibilitätsalias für
`detection:`.

## Installation

```bash
bun add local-pii
```

Die deterministische Erkennung (E-Mail, Telefon, Karten, IBAN, SSN, IP und
URLs) funktioniert in React Native, Browser und Node ohne weitere
Abhängigkeiten.

## Erkennungs-Adapter wählen

- **Expo / React Native** → [`rampart()`](/de/docs/expo) über
  `onnxruntime-react-native`.
- **Browser / Web** → [`rampartWeb()`](/de/docs/browser) über
  `onnxruntime-web` (WASM/WebGPU).

`ner:` wird für Migration unterstützt; neue Anwendungen sollten `detection:`
verwenden.

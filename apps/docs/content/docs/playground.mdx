Everything below runs **in your browser**: no gateway, API route, server action,
API key, or inference endpoint. Choose Chrome's built-in Gemini Nano when the
Prompt API is available, or explicitly download the local Gemma 3 270M fallback.
Then compare the same privacy flow through Vercel AI SDK and TanStack AI.

<Playground />

## Try it

- Send `Email ana@acme.com and repeat it.` in either tab.
- The privacy inspector shows the opaque prompt delivered to the model.
- The assistant response is rehydrated locally, so the UI shows the original
  email again.
- **New chat** clears both the visible history and that tab's in-memory vault.

The tabs have separate histories and separate `PiiSession` instances. Stop
cancels the current browser generation rather than calling a remote service.

## Runtime notes

- Gemini Nano is browser-managed and currently depends on compatible desktop
  Chrome hardware and Prompt API availability.
- The fallback is `onnx-community/gemma-3-270m-it-ONNX`, q4f16, approximately
  426 MB. It is loaded only after explicit consent and requires a compatible
  desktop browser with WebGPU. Review its [model card and Gemma license terms](https://huggingface.co/onnx-community/gemma-3-270m-it-ONNX)
  before downloading.
- Artifact downloads may appear in DevTools Network. Prompts, restored values,
  and the privacy vault are never sent to an application inference server.
- Small local models are useful for this demonstration, but language quality and
  reasoning ability vary. The interface being translated does not guarantee
  equal model quality in English, Portuguese, and German.

The UI uses shadcn and AI Elements primitives. Both examples are real client-side
framework lifecycles; neither hides the other framework as its transport.

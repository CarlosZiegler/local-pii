---
title: Detecção no navegador
description: Execute o adaptador de Detecção Rampart no navegador com onnxruntime-web (WASM + WebGPU).
---

O núcleo TypeScript roda no navegador. `local-pii/web` fornece o adaptador de
**Detecção** Rampart Q4 para encontrar nomes, endereços e IDs antes que um
modelo de Geração receba conteúdo protegido.

```bash
bun add onnxruntime-web local-pii
```

## Detecção sem configuração

```ts
import { createAnonymizer } from "local-pii"
import { rampartWeb } from "local-pii/web"

const privacy = createAnonymizer({ detection: rampartWeb() })
const { redactedText } = await privacy.anonymize("Hi, I'm João Silva")
```

O padrão baixa o modelo de 14,7 MB, vocabulário e labels da origem do Rampart.
Esse download de artefatos não contém conteúdo do usuário. Em produção,
prefira hospedar assets pinados e usar uma Content Security Policy.

## Hospedagem própria

```ts
import { createAnonymizer } from "local-pii"
import { rampartAssets, rampartWeb } from "local-pii/web"

const privacy = createAnonymizer({
  detection: rampartWeb({
    model: "/models/rampart-q4.onnx",
    vocab: rampartAssets.vocab,
    labels: rampartAssets.labels,
    wasmPaths: "/ort/",
    executionProviders: ["webgpu", "wasm"],
  }),
})
```

O adaptador tenta WASM se WebGPU não estiver disponível. Depois escolha um
adaptador de Geração separado ou `runInlineText`. `ner:` continua aceito como
compatibilidade para `detection:`.

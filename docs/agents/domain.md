# Domain docs

Este é um repositório single-context.

Antes de explorar, leia `CONTEXT.md` e os ADRs relevantes em `docs/adr/`, quando existirem. A ausência desses arquivos não bloqueia o trabalho.

Use nos planos, issues, testes e código o vocabulário definido em `CONTEXT.md`. Se uma proposta contradisser um ADR, sinalize o conflito explicitamente.

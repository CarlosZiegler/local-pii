# Issue tracker: GitHub

Issues e PRDs vivem no GitHub. Use `gh` para criar, ler, comentar, rotular e fechar issues.

## Pull requests as a triage surface

PRs externos são uma superfície de triagem: sim.

Considere apenas autores externos (`CONTRIBUTOR`, `FIRST_TIME_CONTRIBUTOR` ou `NONE`). PRs de owners, members e collaborators permanecem fora dessa fila.

Quando uma skill disser “publish to the issue tracker”, crie uma GitHub Issue. Quando pedir o ticket relevante, use `gh issue view`.

Mapas do Wayfinder serão issues com label `wayfinder:map`; tarefas filhas usarão sub-issues e dependências nativas do GitHub quando disponíveis.
